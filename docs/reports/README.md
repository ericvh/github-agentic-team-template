# Reports

Use this directory only when detailed evidence would make the human GitLab
surface harder to read.

- `agent-loops/`: optional MR-local agent, steering, context-boundary, or cost
  reports tied to a named measurement question.
- `methodology/`: evidence matrices and appendices for operating-method reviews.

Do not store credentials, tokens, cookies, secret-bearing session URLs, or raw
reasoning. Prefer compact, reproducible evidence and link it once from GitLab.
